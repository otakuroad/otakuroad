## 1. 제품 정의

- **한 줄**: 아키하바라의 서브컬처 매장을 한 화면 지도에 담고, 각 매장이 무엇을 파는지·지금 여는지·정확히 어디(건물·층)인지 즉시 보여준다.
- **대상**: 아키하바라를 방문하는 한국어·영어권 오타쿠 관광객. 현지에서 걷는 중(모바일)과 여행 전 사전 조사(데스크톱) 둘 다.
- **차별점 (구글 지도 대비)**
  1. 라디오회관·컬처즈존 같은 복합 빌딩을 **층별 디렉토리**로 푼다. 구글 지도는 같은 좌표에 핀 14개를 겹쳐 놓는다.
  2. **출구 기준 도보 분**. 아키바 빌딩 협곡에서 GPS는 30m씩 틀려 옆 건물을 가리킨다.
  3. **신선도**. 카드마다 확인일·출처, 이전·폐점은 날짜 배너. 2025~2026년에만 토라노아나 폐점, BEEP 이전, 스루가야 게임관 이전(9/25 예정), 라신방 개명(9/18 예정) 등 변동이 많았다.
  4. **큐레이션된 한국어·영어 설명**. "무엇을 파는 곳인지" 한 줄과 "찾아가는 법" 마지막 30m 안내.
- **하지 않는 것 (MVP)**: 리뷰·평점, 계정·로그인, 실내 지도, 경로 폴리라인·워킹 모드, 오프라인 PWA, 광고.

## 2. 사용자 시나리오

1. **전기가 출구에 막 나온 사람** — 지도를 열면 출구 기준으로 근처 매장이 정렬돼 있다. "피규어" 칩을 누르고 코토부키야 핀을 탭 → "영업중 · 20:00 마감 · 도보 4분 · 면세" → 길찾기 버튼으로 구글 지도 도보 안내.
2. **라디오회관 앞에 서 있는 사람** — 차콜 건물 핀을 탭 → 층 스택(10F→B1F)이 밖의 세로 간판과 같은 순서로 열린다. "K-BOOKS 3F · 영업중", "카드라보 9F · 영업중" → 행 탭으로 매장 카드.
3. **여행 2주 전 노트북 앞의 사람** — 좌측 패널 목록에서 "레트로 게임" 필터, 기준 시각을 "토요일 11:00"으로 바꿔 어느 매장이 열려 있을지 확인, 하트로 저장. /s/super-potato 링크를 친구에게 공유.

## 4. 화면과 플로우

### 4.1 모바일 (< 900px)

**지도 홈 — 유일한 최상위 화면**
- 전체화면 MapLibre. 아키하바라 bbox 고정(maxBounds 35.696–35.706N / 139.767–139.778E, minZoom 15). 기본 중심은 JR 전기가 출구, z16.5.
- 지도 위 크롬은 4개뿐: ① 상단 검색 필(우측 끝 ⓘ) ② 그 아래 가로 스크롤 칩 행(지금 영업중 · 면세 · 카테고리 10 · 활성 시 좌측에 초기화) ③ 우하단 내 위치 버튼 ④ 하단 논모달 시트. 햄버거·탭바·로고·범례 패널 없음.

**마커**
- 매장 = 카테고리 색 원형 글리프 28px + 흰 2px 링 + 44px 투명 히트 영역. 건물 = 차콜 둥근 사각 32px + 입주 수 배지.
- 선택 = 라벨 달린 티어드롭 40px로 확대, 최상단. 세션 내 방문 = 60% 투명. 필터 제외 = 숨김(회색 아님). 이전·폐점 = 회색 링.
- 라벨은 priority 1 랜드마크만 z16부터, 전체는 z18부터. 베이스맵의 상점 라벨은 bbox 안에서 억제.

**시트 · 대기 상태 = 근처 목록**
- 선택이 없으면 피크(≈18%)에 "근처 42곳 · 전기가 출구 기준 ▾" 한 줄. 앵커 탭으로 전기가 출구 / 쇼와도리 출구 / 스에히로초역 / 현재 위치(GPS 오차 40m 미만일 때만) 전환, 거리·정렬 즉시 재계산.
- 끌어올리면 지도와 같은 필터·정렬의 목록: 44px 사진 썸네일(없으면 카테고리 타일) · 이름(ko/en) · 일본어명 작게 · 영업 상태 · "라디오회관 4F" 또는 "도보 3분" · 면세 배지. 상단 전체/저장됨 세그먼트. 별도 목록 화면 없음.

**시트 · 매장 카드 (3스냅: 피크 18% / 하프 50% / 풀 92%)**
- 드래그 핸들 + 보이는 X. 브라우저·OS 뒤로가기로 닫힘(history.pushState). 배경 탭으로는 닫히지 않음. 피크·하프에서는 지도 조작 가능.
- 피크 = 외관 사진(72px, 없으면 카테고리 타일, 촬영 연도 작게) · 이름 · 일본어명 · 카테고리 칩 · 영업 상태 필 · 위치줄 · 배지 행(면세 / 현금만 / 중고 / R-18층 / 이전·폐점) · 길찾기 버튼 하나. 하프 이상에서 사진이 가로 히어로로 확장.
- 하프 = 한 줄 설명 · 요일별 영업시간표 + 정기휴일 + 메모 · 저장/공유/공식 사이트/X 액션 행 · 단일 체인 타워의 층 가이드.
- 풀 = 찾아가는 법 · 팁 · 이 건물의 다른 매장 · 같은 체인 다른 지점 · 주소 복사 · "2026-09-04 확인" + 출처 + 오류 신고.
- 이전·폐점이면 카드 최상단에 날짜 배너("9/25 이전 재오픈 → 外神田3-15-4 2F", 후속 레코드 링크).

**시트 · 건물 디렉토리**
- 헤더 = 건물명 ko/en/ja · 건물 영업시간 안내 · 입주 수 · 출구 힌트 · 공식 플로어가이드 링크.
- 본문 = 최상층→B1F 순 층 스택. 각 층은 라벨 그룹, 행 = 카테고리 점 · 이름 · 영업 상태 · 면세 배지. 큐레이션되지 않은 층은 회색 한 줄로 접힘("2F · 호비스테이션 외 소형 트레카 매장").
- 필터 활성 시 비매칭 행은 숨기지 않고 흐리게, 건물 핀 배지는 "3/14".
- 행 탭 → 같은 시트 안에서 매장 카드로 교체, 브레드크럼 "라디오회관 › 아미아미 4F", 뒤로가기는 디렉토리 스크롤 위치 복원. 시트 2장 겹침 절대 없음. 입주 8곳 초과 건물만 상단 카테고리 탭.

**검색 오버레이**
- 검색 필 탭 → 전체화면, 자동 포커스. 이름(ko/en/ja/로마자)·synonyms·tags 퍼지 검색("건프라" → 볼크스·요도바시 6F, "포켓몬 카드" → 하레루야2·카드라보).
- 결과는 매장 / 건물 / 카테고리 그룹. 빈 상태 = 바로가기 칩 6개(처음이면 이 길 · 라디오회관 층별 · 지금 열린 곳 · 레트로 게임 · 메이드카페 · 트레카) + 최근 검색.
- 선택 → 오버레이 닫힘, 지도 fly-to, 시트 하프.

- 기준 시각(기본 도쿄 현재 / 방문 날짜·시간 선택 → 모든 영업 상태 재계산) · 기본 출발 지점(출구 3곳) · 언어 전환(ko/en) · R-18 표시 토글(후순위) · 데이터 기준일과 주의문 · 오류 신고·매장 제보 링크 · 저작권(© OpenStreetMap contributors · OpenFreeMap/Protomaps) · 버전.

**"처음이면 이 길" (MVP는 순서 리스트만)**
- 8~10곳 큐레이션 순서 + 정거장마다 한 줄 이유 + 영업시간에서 계산한 출발 추천 시각 + 첫 정거장까지의 출구 안내. 정거장 탭 → 매장 카드(브레드크럼). 폴리라인·워킹모드·체크오프 없음.

### 4.2 데스크톱 (≥ 900px)
- 같은 컴포넌트로 하단 시트 대신 좌측 사이드 패널(≈420px: 목록 / 매장 카드 / 건물 디렉토리, 같은 브레드크럼).
- 목록↔마커 호버 브러싱, ↑/↓·Enter·Esc 키보드 탐색. 지도는 항상 100dvh − 헤더, 스크롤 페이지 안에 절대 넣지 않음.

### 4.3 공유·딥링크 (프리렌더)
- `/{ko|en}/s/{id}` 매장, `/{ko|en}/b/{id}` 건물, `/{ko|en}/c/{category}` 카테고리("아키하바라 피규어·프라모델 샵 N곳"), `/{ko|en}/first`.
- 같은 카드 컴포넌트로 정적 HTML + OG 태그 + JSON-LD(Store) 생성. 링크를 열면 같은 지도 위에 해당 시트가 열린 상태로 로드.
- 필터·선택 상태는 URL 쿼리(`?c=figure_hobby,trading_card&open=1`)에 동기화.

### 4.4 핵심 플로우
- 핀 탭 → 핀이 시트 위에 보이도록 최소한만 팬 → 피크 카드 → 끌어올려 상세 → 길찾기(구글 지도 도보 딥링크) 또는 저장(localStorage) / 공유(navigator.share). 빈 지도 탭 → 대기 목록으로 복귀.
- 칩 필터: 카테고리 칩은 다중 선택 OR, 지금 영업중·면세는 AND. 활성 칩에 실시간 개수. 롱테일 필터(현금만·중고만·R-18)는 지도에 두지 않음.
- 내 위치: 한 번 탭에 한 번 센터링 + 파란 점 + 정확도 링. 팔로우 모드 없음. 정확도 50m 초과 시 토스트.

## 6. UX 원칙

1. **2초 규칙** — 피크 카드는 네 가지만 답한다: 무슨 가게, 지금 여는지, 어디, 알아야 할 것. 액션은 길찾기 하나만.
2. **지도 위 크롬은 4개까지** — 검색 필, 칩 행, 내 위치, 시트.
3. **시트는 하나, 겹치지 않는다** — 매장↔건물↔목록 이동은 같은 시트 안에서 브레드크럼으로. 뒤로가기는 항상 한 단계.
4. **건물은 건물답게** — 입주 매장은 핀을 갖지 않고, 건물 핀 하나가 세로 간판 순서의 층 스택을 연다. 숫자 클러스터 없음.
5. **색만으로 말하지 않는다** — 영업 상태는 텍스트+색, 카테고리는 아이콘+색. 대비 4.5:1, 컨트롤 44px 이상.
6. **출구 기준 방향감** — 지도는 파란 점이 아니라 전기가 출구에서 열리고, 거리는 출구 기준 도보 분. 자동 리센터 없음.
7. **신선도는 기능이다** — 모든 카드에 확인일, 이전·폐점은 날짜 배너, 모르는 시간은 "시간 미확인". 틀린 "영업중"은 없는 것보다 나쁘다.
8. **빈 슬롯이 없다** — 사진 없으면 카테고리 타일, 팁 없으면 섹션 자체가 사라짐. 레이아웃이 데이터 유무로 흔들리지 않는다.

**비주얼**: 흰 바탕, 회색 텍스트 위계, 카테고리 색만 포인트. 산세리프 시스템 폰트(한글은 Pretendard 폴백 검토). 건물 시트와 로고에만 세로 간판/층 스택 모티프.

## 8. 데이터 전략

- **단일 진실 원천** = 저장소의 손 큐레이션 JSON: `data/stores/*.json`, `data/buildings/*.json`, `data/glossary.json`, `data/excluded.json`, `data/first-road.json`. 빌드가 `stores.geojson`·`buildings.geojson`을 생성해 지도 아일랜드가 소비.
- **좌표**: OSM 노드 좌표 우선(`data/osm/overpass-akihabara-2026-09-04.json`, 2,752건 캐시). 매칭 실패분은 국토지리원 주소 검색 API로 号 단위 지오코딩. 모든 핀은 베이스맵 위에서 육안 확인 후 입구 쪽 미세 조정. 런타임 지오코딩·런타임 Overpass 없음. 주의: OSM `level`은 0부터(0 = 일본 1F).
- **영업시간·면세·층**: 각 매장·건물 공식 페이지에서만 옮기고 `hours.source_url` + `verified_at` 기록. 없으면 "시간 미확인".
- **예정 변경**은 `status.effective_date`로 미리 입력해 앱이 당일 자동 전환(라신방→AKIBA Flags 2026-09-18, 스루가야 게임관 2026-09-25 이전 재오픈).
- **폐점·이전 확정 목록**은 `excluded.json` 거부목록(토라노아나, GiGO 1호관, 볼크스 호비천국1, ACOS, 아미아미 2nd 등)으로 두어 OSM 시드가 되살리지 못하게.
- **사진**: v0부터 표시. 1차 출처는 Wikimedia Commons의 CC0/CC BY/CC BY-SA 사진(외관·간판 우선, 사진별 크레딧·라이선스·촬영일 기록, `public/photos/<id>.jpg`로 리사이즈해 자체 호스팅). 2026-09-04 조사 기준 주요 매장 20곳 중 약 15곳에 사용 가능한 사진이 있으나 2009~2015년 촬영분이 섞여 있어 카드에 촬영 연도를 함께 표시한다. 복합 빌딩 입주 매장(라디오회관 3F 등)은 커먼즈에 거의 없으므로 현장 촬영(v1)으로 채운다. 매장 사이트 이미지·로고는 링크만. 크레딧은 풀 카드 하단과 정보 시트의 저작권 목록에 노출.
- **법적**: 구글 Places API는 비구글 지도 사용 금지·30일 캐시 제한이라 쓰지 않음(길찾기 딥링크만). 지도에 OSM 표기 상시. 데이터셋 ODbL 공개.
- **유지보수(솔로)**: 분기마다 `seed:osm` diff → 라디오회관·컬처즈존 플로어가이드 재확인 → 링크 체크 → `verified_at` 갱신을 PR 하나로. 6개월 초과 레코드 자동 목록화. 카드의 "오류 신고"는 매장 id가 채워진 GitHub 이슈 템플릿.
